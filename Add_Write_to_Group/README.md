###Add Write to Group###

This can be used if a 3rd party application requires an update that is not able to be applied through a managed method. This tool should only be used with IT supervision.<br>

Many 3rd party applications are built on standardized frameworks that have their own update methods. These frameworks are inside the application bundle and, when the application is in the /Applications directory, they require administrator privileges to update.<br>
<br>

Add Write to Group is a self service tool that will add the write permission to Group for the app selected in the dropdown menu.
• Only 3rd party apps are available. Jamf apps and Apple apps are excluded.
• Add Write to Group policy.
• The permissions will revert the next time the app updates.
<br>
How to use Add Write to Group<br>
1. Quit the app completely.
2. Launch Add Write to Group.
3. Select the app and click Add.
4. When Add Write to Group has completed relaunch the app.
5. When prompted, update the Helpers.
